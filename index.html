O que é Herança?

Herança é um mecanismo da Programação Orientada a Objetos que permite que uma classe herde características e comportamentos de outra classe.


Superclasse

Classe mais geral, que fornece atributos e métodos.

Subclasse

Classe especializada que herda características da superclasse.

Exemplo do mundo real

Pessoa
↓
Aluno
Professor

Todo Aluno é uma Pessoa.

Todo Professor também é uma Pessoa.

Por que utilizar Herança?

♻️ Reutilização

Evita duplicação de código.

🎯 Especialização

Permite criar classes mais específicas.

🧹 Organização

Centraliza características comuns.

🔧 Manutenção

Alterações na superclasse podem beneficiar subclasses.

Palavra-chave extends

Em Java, utilizamos extends para indicar que uma classe herda outra. 

class Pessoa {

    String nome;
    int idade;

}

class Aluno extends Pessoa {

    String matricula;

}

A classe Aluno possui seus próprios atributos e também recebe os atributos herdados de Pessoa.

Superclasse × Subclasse

Superclasse

  • Classe mais genérica
  • Possui características comuns
  • É utilizada como base
class Pessoa {

    String nome;
    int idade;

}

Subclasse

  • Classe mais específica
  • Herda da superclasse
  • Pode adicionar novos recursos
class Aluno extends Pessoa {

    String matricula;

}

Exemplo prático

class Pessoa {

    String nome;

    void apresentar() {
        System.out.println(
            "Olá, meu nome é " + nome
        );
    }
}

class Aluno extends Pessoa {

    String curso;
}

Aluno aluno = new Aluno();

aluno.nome = "Carlos";
aluno.curso = "Sistemas de Informação";

aluno.apresentar();

O método apresentar() foi herdado!

O que é herdado?

Uma subclasse pode utilizar membros acessíveis da superclasse.


✓ Métodos

Comportamentos definidos na superclasse.

✓ Atributos

Características acessíveis da superclasse.

✓ Comportamentos

A subclasse pode reutilizar funcionalidades.

✗ Construtores

Construtores não são herdados.

A palavra-chave super

super representa uma referência à superclasse. 

class Pessoa {

    String nome;

    Pessoa(String nome) {
        this.nome = nome;
    }
}

class Aluno extends Pessoa {

    String curso;

    Aluno(String nome, String curso) {

        super(nome);

        this.curso = curso;
    }
}

super(nome) chama o construtor da classe Pessoa.

Por que usar super()?

Imagine que a superclasse possui informações que precisam ser inicializadas. 

class Pessoa {

    String nome;

    Pessoa(String nome) {
        this.nome = nome;
    }
}

A subclasse pode delegar essa inicialização: 

class Aluno extends Pessoa {

    Aluno(String nome) {

        super(nome);

    }
}

Sobrescrita de métodos

Uma subclasse pode modificar o comportamento de um método herdado.

Isso é chamado de sobrescrita (override). 

class Animal {

    void emitirSom() {
        System.out.println("Som");
    }
}

class Cachorro extends Animal {

    @Override
    void emitirSom() {
        System.out.println("Au Au!");
    }
}

@Override

A anotação @Override informa ao compilador que estamos sobrescrevendo um método. 

class Animal {

    void emitirSom() {
        System.out.println("Som genérico");
    }
}

class Gato extends Animal {

    @Override
    void emitirSom() {
        System.out.println("Miau!");
    }
}

Boa prática: utilize @Override ao sobrescrever métodos.

Exemplo completo

class Animal {

    String nome;

    void dormir() {
        System.out.println(nome + " está dormindo.");
    }

    void emitirSom() {
        System.out.println("Som...");
    }
}

class Cachorro extends Animal {

    @Override
    void emitirSom() {
        System.out.println("Au Au!");
    }
}

class Gato extends Animal {

    @Override
    void emitirSom() {
        System.out.println("Miau!");
    }
}

Testando as subclasses

public class Main {

    public static void main(String[] args) {

        Cachorro cachorro = new Cachorro();
        cachorro.nome = "Rex";

        Gato gato = new Gato();
        gato.nome = "Mimi";

        cachorro.dormir();
        cachorro.emitirSom();

        gato.dormir();
        gato.emitirSom();
    }
}

Cada classe possui seu próprio comportamento.

Herança com protected

O modificador protected permite acesso pela própria classe e pelas subclasses. 

class Pessoa {

    protected String nome;

}

class Aluno extends Pessoa {

    void mostrarNome() {

        System.out.println(nome);

    }
}

Entretanto, em projetos reais, normalmente devemos avaliar cuidadosamente se o uso direto de atributos é realmente necessário.

Herança não é copiar e colar

Herança representa uma relação:


É um

Um Cachorro é um Animal.

Um Aluno é uma Pessoa.

Um Professor é uma Pessoa.


Regra prática: pense "X é um Y?" antes de criar uma herança.

Exemplo: Sistema Acadêmico

class Pessoa {

    String nome;
    String cpf;

    void apresentar() {
        System.out.println(
            "Nome: " + nome
        );
    }
}

class Aluno extends Pessoa {

    String matricula;

    void estudar() {
        System.out.println(
            nome + " está estudando."
        );
    }
}

class Professor extends Pessoa {

    String disciplina;

    void ensinar() {
        System.out.println(
            nome + " está ensinando " + disciplina
        );
    }
}

Utilizando o sistema

Aluno aluno = new Aluno();

aluno.nome = "João";
aluno.cpf = "123";
aluno.matricula = "2026001";

aluno.apresentar();
aluno.estudar();


Professor professor = new Professor();

professor.nome = "Maria";
professor.disciplina = "Java";

professor.apresentar();
professor.ensinar();

Herança + Polimorfismo

Uma referência da superclasse pode apontar para objetos das subclasses. 

Animal animal1 = new Cachorro();
Animal animal2 = new Gato();

animal1.emitirSom();
animal2.emitirSom();

Mesmo tipo de referência, comportamentos diferentes.

Isso é um dos fundamentos do polimorfismo.

Exercício 3 — Desafio

Desenvolva um pequeno sistema de veículos.


Crie:

  • Veiculo
  • Carro
  • Moto
  • Caminhao

Cada veículo deve sobrescrever o método acelerar().

Depois crie um vetor de Veiculo contendo diferentes tipos de veículos.

Desafio — solução

class Veiculo {

    void acelerar() {
        System.out.println(
            "Veículo acelerando"
        );
    }
}

class Carro extends Veiculo {

    @Override
    void acelerar() {
        System.out.println(
            "Carro acelerando..."
        );
    }
}

class Moto extends Veiculo {

    @Override
    void acelerar() {
        System.out.println(
            "Moto acelerando..."
        );
    }
}

class Caminhao extends Veiculo {

    @Override
    void acelerar() {
        System.out.println(
            "Caminhão acelerando..."
        );
    }
}

Resumo

Herança permite reutilizar e especializar código.


extends → cria a herança

super → acessa a superclasse

@Override → sobrescreve métodos


Herança é uma das principais ferramentas da Programação Orientada a Objetos.

Atividade prática

Desenvolva um sistema utilizando herança em Java.


O sistema deve possuir pelo menos:

  • 1 superclasse
  • 3 subclasses
  • atributos
  • métodos
  • construtores
  • uso de super()
  • pelo menos um @Override

Pense em um sistema de banco, escola, veículos, loja ou empresa.
